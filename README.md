# YAMAHA RX-V6A — промо-сайт

Строгий промо-лендинг в цветах Yamaha (чёрный / белый / красный `#E60012`):

1. **Герой** — белые буквы YAMAHA с чёрным контуром; при скролле разлетаются как салют  
2. **Сборка** — буквы собираются в аккуратную надпись YAMAHA + модель RX-V6A  
3. **Характеристики** — три студийных ракурса с линиями к ключевым параметрам  
4. **Почему она** — текст выплывает в том же строгом стиле  

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

Vercel: Framework = Vite, Output = `dist` (см. `vercel.json`).
