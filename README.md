# YAMAHA RX-V6A — промо-сайт

Цветной скролл-лендинг для AV-ресивера Yamaha:

1. Герой с надписью **YAMAHA**, буквы расходятся при прокрутке
2. Три ракурса аппарата с линиями к ключевым характеристикам
3. Текст «почему именно она» с появлением строк при скролле
4. Живой цветной фон (canvas + цветовые пятна), оттенки меняются при листанье

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```
